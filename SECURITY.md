# Politique de sécurité

## Versions prises en charge

Seule la branche `main` du preview public reçoit actuellement les correctifs.

## Signaler une vulnérabilité

N’ouvrez pas d’issue publique pour :

- fuite de secret ou de données privées;
- prompt injection exploitable;
- contournement d’autorité;
- commande destructive non bornée;
- provenance ou téléchargement non fiable;
- preuve falsifiable présentée comme vérifiée.

Utilisez le formulaire privé GitHub :

<https://github.com/charlescstpierr/azdone/security/advisories/new>

Incluez une reproduction minimale, l’impact, les fichiers concernés et toute
mitigation connue. Retirez secrets, données client et chemins privés.

## Délai

Le mainteneur vise un accusé de réception sous sept jours. Aucun délai de
correction n’est garanti pendant le preview.

AZDone étant un ensemble d’instructions, une vulnérabilité peut venir du skill,
du host, d’un outil appelé ou d’une mauvaise frontière d’autorité. Le rapport
doit distinguer ces couches lorsque possible.
