# Détails de livraison AZDone

## Integration

Integrate only accepted candidates, in dependency order, with reversible native Git operations. Keep rejected branches and their evidence recoverable until the integrated result is accepted. Resolve conflicts only when the expected behavior is evidenced; otherwise return the issue to the responsible module.

## Verification And Handoff

Verify the integrated result with fresh project-native checks. A handoff is complete only when another agent can resume from the current state using exact commands, artifacts, risks, next transition, and rollback conditions.

## Authority

Check explicit authority separately for push, pull request, merge, deploy, discard-branch, and any production mutation. Authority for one action never implies authority for another. Without matching authority, prepare local artifacts, choose keep-local, and return authority-request.

## Canary And Rollback

Prepare canary, monitoring, and rollback before deploy. Do not deploy if these artifacts are absent; report partial or blocked. Clean ambiguous branches or worktrees only after integrated acceptance and explicit authority.
